# Hướng dẫn làm việc trong project

## Dừng server sau khi hoàn tất task

- Sau khi hoàn tất mỗi task, phải dừng local/dev/preview server do agent khởi chạy để chạy hoặc kiểm thử project.
- Trước khi trả lời hoàn tất, kiểm tra server đã dừng và port đã được giải phóng.
- Chỉ dừng process của project do agent khởi chạy; không dừng server hoặc process khác của người dùng.
- Chỉ giữ server chạy nếu người dùng yêu cầu rõ ràng trong task hiện tại.
